# v1.1.0 Release Notes

Release date: 2026-07-11

## Highlights

- Added first-class **TranslateGemma** support as an optional translation engine (`translation.engine: translategemma`) with configurable model ID and Hugging Face token flow for gated access.
- Added per-file processing summary at the end of each input file:
  - Total processing speed
  - Media duration
  - Elapsed processing time
- Added multi-file batch summary output:
  - Aggregate counts (succeeded, no-speech, failed)
  - Total media duration, elapsed time, and overall speed
  - Per-file stats list (status, media, elapsed, speed)
- Optimized isolated translation flow to load translator weights once per file, including non-English pivot workflows.
- Fixed pivot batch-worker data-shape regression and added regression coverage tests.
- Consolidated local validation into `run_local_pipeline.ps1` and removed the legacy `run_tests_with_coverage.ps1` script.
- Updated coverage artifact usage to `assets/coverage.svg`.

## Translation Pipeline Changes

- Added runtime translation engine selection (`nllb` or `translategemma`) through `config.yaml`.
- Pivot-to-English and target-language passes now run within a single isolated batch-worker lifecycle.
- This eliminates duplicate model initialization and improves translation startup performance.

## Tooling and Quality

- Added/updated local gate sequence:
  - Ruff
  - Flake8
  - Pylint
  - Pytest coverage (>= 90%)
  - Coverage badge and summary generation
- Added Poetry project metadata and dependency configuration (`pyproject.toml`).
- Hardened CI defaults with workflow-level read-only repository permissions and checkout credential persistence disabled.

## Reliability and UX

- Preserved existing resume and atomic subtitle save behavior.
- Added clearer end-of-file summary metrics for processing performance tracking.

## Notes

- TranslateGemma is supported for high-quality translations on high-VRAM systems and requires gated-model access via Hugging Face authentication.
- `nllb` remains the default translation engine.
