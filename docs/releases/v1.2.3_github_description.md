Every temporary file the pipeline creates for a video now lives in one
per-video work directory, `<video name>.asg-temp/`. Interrupted runs resume
from the last completed stage; finished runs leave nothing behind. No changes
to CLI flags, configuration, or deliverable filenames.

______________________________________________________________________

## 🗂️ One work directory per video

Only `<base>.<lang>.srt` and `<base>_multilang.<ext>` are written next to the
input video. Everything else moves into `<base>.asg-temp/`: the extracted
`_temp.wav`, the isolated `_(Vocals)_*.wav` stem, `common_input.json`,
`manifest.json`, `pivot_pivoted.json`, the `.temp_output.*.json` worker
outputs, `source_lang.txt`, and every in-flight `.asg-tmp-*` scratch entry.

## 💾 Resume after a crash or power outage

The old code cleaned up from a `finally` block on **every** exit, so a crash
or `Ctrl+C` destroyed the extracted audio and isolated vocals — the two most
expensive intermediates. That is inverted:

| Outcome | Work directory |
| --- | --- |
| Muxed, no speech, or already done | removed |
| Failure, exception, `Ctrl+C`, power loss | **kept for resume** |

The translation worker now keeps its manifest, input, and English pivot when
it fails, instead of deleting them. Verified on real media: force-killing the
process tree mid-translation and re-running skipped transcription, reused the
English pivot, and translated only the remaining 32 of 36 languages.

## 🧹 Nothing left behind

- `movie.source_lang.txt` was never swept and survived every completed video.
  Fixed, and the legacy sweep now also removes sidecars left beside videos by
  v1.2.2 and earlier.
- `Ctrl+C` during muxing leaked the mux scratch file (`KeyboardInterrupt` is a
  `BaseException`, so the old `except (OSError, RuntimeError, ValueError)`
  never fired). It is now discarded in a `finally`.

## 🎛️ Tunes itself to the card

Validating on an RTX 3080 Laptop (8 GB) caught the old static config running
NLLB-3.3B on the *CPU*: its 6.3 GB of weights did not fit, loading hit 130
OOM retries, and a silent fallback left the GPU at 160 MiB and 0.4x
realtime. Now `models.nllb: auto` picks the largest NLLB whose weights fit
60 % of usable VRAM (3.3B from 11 GB, distilled 1.3B from 5 GB, distilled
600M below), Whisper drops to int8 weights under 6 GB, and the worker sizes
its batch from the VRAM actually free after loading, so a shared or small GPU
gets a smaller batch instead of a CPU fallback (which is now logged). Cues
are batched by length to keep padding small. `performance.max_vram_usage_gb`
is honoured. Constants are calibrated measurements from the RTX 5090.
Validated on the 3080: distilled 1.3B on the GPU, batch 10 on a card shared
with two other jobs, zero CPU fallbacks, 36 languages in 3:42 instead of
over 7 minutes each.

## 🎞️ Multi-hour videos

Vocal separation loaded the whole file into RAM at 44.1 kHz stereo float
and wrote a stem of the same shape: a 4-hour input meant a 5 GB array before
the model started and a stem past the 4 GB WAV limit. Inputs longer than the
new `separation_chunk_minutes` (default 30, `0` disables) are now separated
in chunks with 2 s of context on each side, downmixed to 16 kHz mono, and
joined. Each finished chunk is resume state, so a power loss costs at most
one chunk. Peak RAM is ~3 GB per chunk and every intermediate stays under
1 GB. Validated on real hardware: the cue spanning a chunk seam matched the
unchunked transcript to within 20 ms. Extraction now enables RF64 so a >17 h
source WAV stays valid; Whisper, translation and muxing already stream.

## ✅ Validated resume, not blind resume

- The work directory is stamped with the input's size and mtime; a video
  replaced by another file of the same name discards the old state and
  ignores the SRT files beside it for that run, instead of resuming from
  the wrong audio or the wrong subtitles.
- A resumed vocal stem must probe to the same duration as `_temp.wav`
  (±2 s); one truncated by a power cut is discarded and redone.
- A resumed `pivot_pivoted.json` must match the current segments' cue timings;
  a stale one is discarded and the pivot pass reruns.

## 🔒 Security posture preserved

The work directory is pipeline-created but lives in an untrusted input folder,
so it inherits the v1.2.2 rules: a symlink or junction at the work-directory
name is refused (`SymlinkRefusedError`), and the purge **never recurses** —
files and links are unlinked (links never followed), `.asg-tmp-*` directories
are emptied one level down and `rmdir`-ed, and anything unrecognised is left
in place and reported. Audio-Separator, which writes predictable stem names,
now writes into a private `0700` scratch directory instead of the input
folder.

`safe_io.reserve_temp_path` and `atomic_text_writer` gained an optional
`scratch_dir`, so writes destined for the input folder still stage inside the
work directory.

## 🔧 Toolchain

- `.gitattributes` pins LF, so Windows clones no longer fail Taplo or export
  CRLF scripts; the Windows gate runs to completion.
- pip-audit now audits `poetry.lock` for the running platform via
  `tests/tools/lock_requirements.py` in both gates and CI, instead of a
  first-entry parse that flagged a PyPy-only torch version, or a CI venv that
  never contained torch.
- Review follow-ups: chunk joins work with relative input paths (absolute
  concat manifest entries), a pinned `nllb_batch` survives hardware
  detection in the worker, fractional `max_vram_usage_gb` is honoured,
  malformed pivot files are regenerated instead of crashing the worker, and
  the lock audit ignores Poetry's `<empty>` marker entries.
- `--cpu` really runs on the CPU: torch 2.14 ignored the empty
  `CUDA_VISIBLE_DEVICES`, so the flag now hides devices with `-1` and every
  CUDA probe also requires a device count. Redirecting output to a file on
  Windows no longer crashes on non-ASCII transcript text.

## ⬆️ Upgrade notes

- Stray temp files from an interrupted v1.2.2 run are swept automatically the
  next time that video completes.
- A work directory left by an interrupted v1.2.3 run is intentional — it is
  the resume state.
- Automation globbing the input folder for `*_temp.wav` or `*.manifest.json`
  should look inside `<base>.asg-temp/` instead.

## Breaking changes

- **Temporary artifacts moved out of the input folder** into
  `<base>.asg-temp/`. Automation globbing the input folder for `*_temp.wav`,
  `*.manifest.json`, `*.common_input.json`, `*.pivot_pivoted.json`,
  `.temp_output.*.json` or `*.source_lang.txt` must look inside that directory
  instead. Those paths were documented in the v1.2.2 release notes.
- **An unfinished run now leaves `<base>.asg-temp/` behind on purpose** as its
  resume state, where earlier releases always cleaned up. Tooling that asserts
  the input folder holds nothing but the video and its deliverables needs
  updating.
- **`models.nllb` now defaults to `auto`.** Cards under 11 GB translate with
  the distilled 1.3B; set an explicit id to keep the 3.3B.
- Deliverable names and CLI flags are unchanged. See the upgrade notes above.
