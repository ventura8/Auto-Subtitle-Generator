A maintenance release that clears the 28 findings the v1.2.5 SonarQube Cloud
analysis left open.
No changes to CLI flags, configuration, deliverable filenames, or pipeline
behaviour.

## 🔒 Supply-chain hardening

- **CI installs wheels only.** `ci.yml` sets
  `POETRY_INSTALLER_ONLY_BINARY=":all:"`, so no dependency's setup script runs
  on a runner. `diffq`, which ships no Python 3.12 wheel, is the single
  exception, allowed only in the Linux real-ML E2E job.
- **Docker image no longer copies the whole build context.**
  `docker/Dockerfile.ubuntu` copies an explicit list of files and directories
  instead of `COPY . /app`, so local secrets, caches or media can't end up in
  the image.

## 🧹 Code quality

- Win32 console mode and control-event values in `logging_utils.py` are named
  constants instead of commented-out numbers.
- Loops that remove items while iterating now snapshot with `.copy()`, which
  states the intent instead of looking like a redundant `list(...)`.

## 🧪 Tests

- Tests that assigned module globals directly (17 findings) now use
  `patch.object`, so the original value comes back even when an assertion
  fails. One of them had left `auto_subtitle.torch` replaced by a mock for
  the rest of the session.

## Breaking changes

- None.
