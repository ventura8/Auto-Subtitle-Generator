Hardens the final mux against tampered subtitle sidecars and bumps `urllib3`
for three new advisories. No changes to CLI flags, configuration, or
deliverable filenames.

## 🔒 Subtitle mux inputs

A party able to write the input folder could replace the source `.srt` with a
symlink to another video during translation, and FFmpeg would copy that
video's picture and audio into the `_multilang` output. Every subtitle
sidecar is now refused when it is a link, validated, opened without following
links, validated again through that open file, and passed to FFmpeg as
`-f srt` with only its subtitle streams mapped.

## 📦 Dependencies

- `urllib3` 2.8.0 (PYSEC-2026-4175, PYSEC-2026-4176, PYSEC-2026-4177).
