Keeps everything a model reads or writes out of the input folder's reach,
binds the translation worker to its work directory, hash-locks the pip/Poetry
bootstrap, and updates all dependencies (torch 2.15).

## 🛡️ Security

- **Private audio stage** (`modules/media/audio_stage.py`): work-directory
  audio is copied into a private `%TEMP%` directory through a no-follow
  descriptor *before* any model loads. Audio-Separator reads and writes only
  there, so a link planted at its predictable stem name can no longer
  overwrite a file, and Whisper / Canary / Parakeet never reopen a
  work-directory file that could have been swapped for a link.
- **Held worker directory** (`modules/held_dir.py`): the translation worker
  holds the work directory from manifest validation on and reaches every job
  file through it (`dir_fd` + `O_NOFOLLOW` on POSIX, identity re-checks on
  Windows). JSON is written through the descriptor of an exclusively created
  entry; `mkstemp` → close → reopen is gone. The parent reads worker outputs
  without following links.
- **Hash-locked bootstrap**: installers and CI install pip 26.2.2 and Poetry
  2.4.3 from `bootstrap-requirements.txt` with `--require-hashes`.
- A FIFO planted at a bound name is refused instead of hanging the run.

## ⬆️ Dependencies

- torch 2.15.0+cu132, torchvision 0.29.1+cu132, cuDNN 9.26.0.51,
  transformers 5.22, audio-separator 0.48, plus refreshed dev tooling and
  lock file. PyAV stays below 19 until faster-whisper supports it.

## ✅ Validation

- Regression tests plant links during mocked model loads and assert victim
  files are never read or written.
- Full local quality gate passes: zero suppressions, Radon grade A,
  ≥ 90% per-file coverage.

## Breaking changes

None.
