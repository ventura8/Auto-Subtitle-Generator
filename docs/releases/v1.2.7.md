# Auto-Subtitle-Generator v1.2.7 — PowerShell Lint Clean-Up

## Release Summary

v1.2.7 clears the last two SonarQube Cloud findings on `main` and fixes a
PowerShell lint check that never ran. There are no changes to the subtitle
pipeline, CLI flags, configuration keys, or deliverable filenames.

______________________________________________________________________

## Cognitive Complexity (`powershelldre:S3776`, 2 findings)

The first analysis after v1.2.6 enabled SonarQube Cloud's PowerShell rules and
flagged two functions in `.github/scripts/Invoke-PowerShellLint.ps1` over the
cognitive-complexity limit of 15:

| Function | Before | Change |
| --- | --- | --- |
| `Get-FunctionCyclomaticComplexity` | 16 | Node weighting moved to `Get-DecisionNodeWeight`; node matching to `Test-AstIsAnyType` over a shared `$script:DecisionAstTypes` list. |
| `Test-PowerShellComplexity` | 17 | Per-file work moved to `Get-ScriptViolation`, per-function checks to `Get-FunctionViolation`, and record construction to `ConvertTo-LintViolation`. |

The cyclomatic-complexity counts are unchanged. A harness loaded the old and
new function definitions and compared their output for all 38 functions in
the repository's PowerShell scripts, the old linter itself, and a fixture
covering every counted node type. The results matched exactly, and so did
the parse-error and missing-file reports.

## Nesting-Depth Check Now Runs

`Get-MaximumFunctionNestingDepth` updated `$maxDepth` from inside the script
block passed to `Ast.FindAll`. PowerShell runs that block in a child scope, so
the assignment created a local variable and the function always returned 0:
`-MaxNestingDepth 4`, passed by both `run_local_pipeline.ps1` and CI, never
failed anything. The depth is now computed by `Get-StatementNestingDepth` in a
plain loop over the function's statements, counting a nesting statement as
one level itself so an empty innermost block (`for (;;) {}`) is not missed.
No function in the repository exceeds depth 4, so the gates still pass; a
fixture nested five levels deep is now rejected, where the old script accepted
it.
