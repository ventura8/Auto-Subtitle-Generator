# Auto-Subtitle-Generator v1.1.3 — Security Hardening + Automated GitHub Releases

This release removes a credential-persistence risk, pins the FFmpeg download
with a SHA256 integrity check, ships an automated GitHub Release workflow, and
updates core dependencies.

______________________________________________________________________

## 🔐 Security & Correctness

- **Removed HF token write-back to `config.yaml`**: the Hugging Face token
  entered at the interactive prompt was previously silently persisted to disk.
  It is now only held in `os.environ["HF_TOKEN"]` for the lifetime of the
  process — `_save_token_to_config` and its helpers
  (`_atomic_write_text_file`, `_escape_token_value`, `_upsert_hf_token_line`)
  have been removed entirely from `modules/configuration/config.py`.

- **Pinned + verified FFmpeg download**: `install_dependencies.ps1` previously
  fetched the rolling `master-latest` URL. It now downloads a pinned build
  (`n9.0.1-6-g9d4ca21220-win64-gpl`) and verifies its SHA256 checksum before
  extraction; a mismatch raises a hard error.

## 🚀 Automated GitHub Releases

- New `.github/workflows/release.yml` — push a `v*` tag and a GitHub Release
  is created automatically:
  1. Validates the tag equals `pyproject.toml` version via
     `scripts/release-verify-tag-version.sh`.
  1. Uses `docs/releases/v{VERSION}_github_description.md` as the release body
     when present; falls back to GitHub auto-generated notes otherwise.

## 🤖 Agent Skills

All 11 modular skills under `.agents/skills/` have been fully rewritten to
structured `SKILL.md` format with YAML frontmatter:
`architecture-review`, `code-linter`, `docs-sync`, `fix-file`,
`model-optimizer`, `pipeline-runner`, `pr-comment-resolution`,
`release-prep`, `review-with-coderabbit`, `setup-dependencies`, `test-runner`.
