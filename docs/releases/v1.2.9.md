# Auto-Subtitle-Generator v1.2.9 — SonarQube Clean-Up

## Release Summary

v1.2.9 clears the last open SonarQube Cloud issue on `main`. There are no
changes to the subtitle pipeline, CLI flags, configuration keys, or
deliverable filenames.

______________________________________________________________________

## Generator Cleanup in a `finally` Block (`python:S9152`)

`atomic_text_writer` in `modules/safe_io.py` discarded its scratch file from
an `except BaseException:` block after the `yield`. SonarQube Cloud flags that
form because cleanup after a `yield` can be skipped on an early exit. The
cleanup now runs in a `finally` block guarded by a `promoted` flag, the same
pattern `_mux_and_promote` uses. The scratch file is still discarded on every
exit that is not a promotion, including a failed promotion, Ctrl+C, and
generator close.
