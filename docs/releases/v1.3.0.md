# Auto-Subtitle-Generator v1.3.0 — NVIDIA Canary and Parakeet, Routed per Language

## Release Summary

v1.3.0 adds NVIDIA Canary-1B-v2 and Parakeet-TDT-0.6B-v3 as speech recognition
engines next to faster-whisper, and makes per-language routing the default.
The pipeline detects the spoken language with Whisper, then transcribes with
whichever engine measured best for that language: Canary for Romanian,
Bulgarian, Croatian, Estonian, Latvian, Lithuanian, Maltese, Slovak and
Slovenian; Whisper for every other language.

The default was decided by measurement, not by published numbers. On the full
FLEURS test splits, with diacritics counted, Canary cut word errors by 20-73 %
relative in each routed language; on Romanian it went from 8.91 % to 6.90 %,
from 10.14 % to 6.45 % on parliamentary speech, and from 17.2 % to 7.4 % on a
35-minute long-form file, with cue timing three times tighter. Whisper stayed
as good or better in English, German, French, Spanish, Italian, Portuguese,
Dutch, Polish, Russian, Ukrainian, Czech, Hungarian, Greek and the Nordic
languages, so those keep it.

Both NVIDIA models run through the `transformers` release already in the lock.
There is no NeMo and no new runtime dependency.

## What Changed

### Engines and routing

- `--asr whisper|canary|parakeet|auto` and the new `asr:` config section
  (`engine`, `routes`, `max_segment_seconds`). `auto` is the default.
- Language identification votes over 8 windows spread across the file's
  speech. faster-whisper's own `detect_language` stops at the first window
  above 0.5, so a 35 s English intro used to decide a Romanian film.
- An unsupported language, a model that does not load or fit the free VRAM,
  or output that is mostly empty falls back to Whisper with a logged warning.
  Nothing falls back silently.
- `whisper.force_detected_language`, documented but previously unused, now
  feeds the vote to Whisper.

### Long inputs and memory

- The NVIDIA path streams 16 kHz audio and runs Silero VAD block by block, so
  multi-hour inputs never sit in RAM. A non-16 kHz input longer than 30 minutes
  is transcoded once to `<base>_asr16k.wav` in the work directory.
- Canary and Parakeet load in bf16 on GPUs with native bf16 (1.9 GB and
  1.2 GB), fp32 elsewhere, and are offloaded before translation. On an 8 GB
  RTX 3080 Laptop, Canary plus NLLB distilled-1.3B fit with 2.9 GB to spare.

### Robustness

- Guard for transformers #49388: Parakeet TDT decoding skipped the per-frame
  symbol cap and could loop. A version-guarded patch restores the cap, and
  batched rows no longer emit tokens past their own audio.
- Degenerate output (repeats, implausible characters per second, low
  confidence) is filtered. If almost nothing decodes, the file is redone with
  Whisper instead of being reported as "no speech" and purged.
- Switching engines regenerates translated subtitles whose timings no longer
  match the new source, including the English pivot.
- Maltese now maps to `mlt_Latn` (previously translated as English).
- Corrupt `safetensors` downloads are purged and re-fetched like the other
  model caches.

### Installer

- `install_dependencies.ps1` pinned an FFmpeg autobuild that upstream deleted,
  so fresh Windows installs failed. It now pins the versioned gyan.dev 9.0.2
  build (SHA-256 verified), uses an installed FFmpeg first, and exits non-zero
  on a failed download or hash check.

## Verification

Benchmarks ran on three machines with `python -m tests.tools.asr_benchmark`
(new; optional `bench` Poetry group for pyarrow). Full tables are in
[docs/hardware_optimization.md](../hardware_optimization.md#benchmark-results).

| Check | Whisper large-v3 | Canary-1B-v2 | Parakeet-TDT-0.6B-v3 |
| --- | --- | --- | --- |
| FLEURS-ro WER, 883 utts (RTX 5090) | 8.91 % | **6.90 %** | 12.60 % |
| VoxPopuli-ro WER, 1330 utts | 10.14 % | **6.45 %** | 9.15 % |
| Romanian diacritic errors | 7.22 % | **2.86 %** | 4.51 % |
| Long-form ro WER / cue onset | 17.2 % / 1.24 s | **7.4 % / 0.41 s** | 11.9 % / 0.43 s |
| RTF, RTX 3080 Laptop | 0.083 | **0.005** | 0.027 |
| RTF, Core Ultra 7 255H CPU | 0.603 | 0.071 | **0.055** |

- Full pipeline (`--asr whisper`, `auto`, `parakeet`, and an engine switch)
  completed on the RTX 3080 Laptop (Ubuntu), the Intel NUC CPU, and the
  RTX 5090 (Windows 11).
- `run_local_pipeline.sh` and `run_local_pipeline.ps1` pass: zero suppressions,
  radon grade A everywhere, coverage at least 90 % overall and per file.
- `tests/e2e/test_real_nvidia_asr.py` checks the Parakeet guard on a tiny
  random model without downloads, and both real checkpoints on CPU when
  `ASG_E2E_NVIDIA_ASR=1` (new `e2e_nvidia_asr` CI job).

## Documentation

AGENTS.md gains an ASR Engines contract and the corrected complexity rule
(radon grade A, CC 1-5). README, docs/, `.github` instructions and skills
describe the engines, routing, the `asr:` section and CC-BY-4.0 attribution for
the NVIDIA models. Version bumped to 1.3.0 in `pyproject.toml` and the
`modules/configuration/version.py` fallback.

## Upgrade Notes

- Without an `asr:` section, an existing `config.yaml` gets the new default
  (`auto` with the shipped routes). Set `asr.engine: whisper` to keep the old
  behaviour.
- The first routed run downloads Canary (3.9 GB) once.
- An existing `<base>.<lang>.srt` beside a video is still reused; delete it to
  re-transcribe with a different engine.

## Breaking Changes

- None to CLI flags or file names. The default transcription engine changes
  for the nine routed languages.
