Hardens resume and translation pivot logic against planted sidecar SRT symbolic
links, preventing victim subtitle text from being loaded as transcription or leaked
into translated outputs.

## 🛡️ Security

- `_read_resume_srt` in `auto_subtitle.py` checks `is_link` and binds descriptors
  with `bind_input` so a planted sidecar symlink is refused with a warning rather
  than treated as valid transcription.
- `_load_reusable_pivot_srt_data` and `_classify_target_language_state` in
  `modules/pipeline/translation.py` check `is_link` and bind descriptors via
  `bind_input`, refusing planted symlinks for English pivot reuse or target
  language skips.
- `modules/subtitles/srt_io.py` validates and parses SRTs without following
  symbolic links (`O_NOFOLLOW` / `_safe_srt_opener` refusing symlinks and
  junctions).

## ✅ Validation

  `tests/modules/utils/test_utils_behavior.py` asserting planted sidecar symlinks
  are refused without leaking victim cues.
