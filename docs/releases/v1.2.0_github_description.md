# Auto-Subtitle-Generator v1.2.0 — Cross-Platform Support + Full E2E Testing

v1.2.0 brings native Linux and macOS support, a real-dependencies E2E test suite
that runs with zero mocks, a Docker cross-platform validation harness, and a
three-OS GHA CI matrix (Ubuntu + macOS + Windows).

______________________________________________________________________

## 🐧 Linux & macOS Native Support

- `install_dependencies.sh`, `run_local_pipeline.sh`, `start.sh` — Bash equivalents
  of the existing PowerShell scripts. Works on Ubuntu 26.04, Debian, macOS, and WSL2.
- FFmpeg path discovery, CPU/GPU detection, and path handling are now fully
  cross-platform (`os.path`, no Windows-only assumptions).
- Radon A-grade compliance enforced: decomposed high-complexity functions in
  `hardware_utils.py` and `models.py`.

## 🐳 Docker Cross-Platform Harness

- `docker/Dockerfile.ubuntu` — Ubuntu 26.04 + Python 3.12.13 via `uv` + full
  dependency install + E2E test run.
- `docker/docker-compose.test.yml` — covers Ubuntu (`ubuntu:26.04`),
  macOS (`dockurr/macos`), and Windows (`dockurr/windows`).
- Run Ubuntu platform locally: `./docker/run_cross_platform_tests.sh ubuntu`

## 🧪 Real-Dependencies E2E Tests

Four new zero-mock tests under `tests/e2e/test_real_pipeline.py`:

1. Real FFmpeg audio extraction + duration check
1. Real GPU/CPU hardware detection
1. Real NLLB-200 distilled-600M translation (subprocess-isolated, CPU)
1. Real CLI `--help` smoke test

All 4 tests pass on Ubuntu host, Ubuntu 26.04 Docker, and GHA Ubuntu runner;
macOS and Windows runners run the smoke-test subset (`real_nllb_translator_cpu_execution` is excluded).

## ⚙️ CI/CD — tri-OS GHA E2E Matrix

`e2e_real_dependencies` now runs on `ubuntu-latest`, `macos-latest`, and
`windows-latest`. Local `run_local_pipeline.sh` mirrors GHA steps exactly.

## 🔧 Import Safety

The optional `torchaudio` backend is not installed for text translation, so
Transformers does not load an incompatible CUDA audio extension.
