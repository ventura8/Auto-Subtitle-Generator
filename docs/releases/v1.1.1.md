## Motivation

Regular dependency updates ensure:

- **Security**: Latest security patches and vulnerability fixes
- **Performance**: Optimized implementations and improved hardware compatibility
- **Stability**: Tested and stable versions of tools and libraries
- **Compatibility**: Better support for Python 3.12+ and RTX 5090/Ryzen 9950X3D
  hardware

## Installation

Run the dependency installer to update your local environment:

```powershell
./install_dependencies.ps1
```

This will update your Poetry lock file and install all latest versions in your
`.venv`.

## Compatibility

All dependencies maintain compatibility with:

- Python 3.12
- Windows 11/10
- CUDA 13.2
- RTX 5090 and RTX 50-series GPUs
- AMD Ryzen 9950X3D and newer Ryzen 9000-series processors
