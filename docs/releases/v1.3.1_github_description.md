Hardens chunked vocal separation so predictable scratch names under the
per-video work directory cannot overwrite a victim file through a planted
symlink.

## 🛡️ Security

- `write_audio_window` writes through a `safe_io` reservation and promote;
  FFmpeg `-y` never targets `chunk_NNN.wav` (or any other destination) by
  pathname.
- `concat_audio_files` writes `stems.list` through `atomic_text_writer` and
  joins into a reserved scratch file before promote.
- Planted links at those names raise `SymlinkRefusedError`; dummy victims in
  the regression tests stay intact.
- Callers pass the final destination only (no nested outer reservation), so
  the join promote cannot see a replaced inode as tampering.

## ✅ Validation

- Targeted ffmpeg chunk-helper tests plus the full local quality gate.

## Breaking changes

None.
