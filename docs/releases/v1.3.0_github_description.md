Adds NVIDIA Canary-1B-v2 and Parakeet-TDT-0.6B-v3 next to faster-whisper and
routes each language to the engine that measured best. Canary now transcribes
Romanian, Bulgarian, Croatian, Estonian, Latvian, Lithuanian, Maltese, Slovak
and Slovenian; Whisper keeps every other language.

## 🎙️ Speech recognition

- `--asr whisper|canary|parakeet|auto` and an `asr:` config section; `auto` is
  the default.
- Romanian on FLEURS: 8.91 % → 6.90 % WER with diacritics counted; long-form
  17.2 % → 7.4 % with cue timing three times tighter.
- Language detection votes across the whole file, so an English intro no
  longer decides the language.
- Every fallback to Whisper is logged; none is silent.
- Runs through the existing `transformers`: no NeMo, no new runtime
  dependency.

## 🛡️ Robustness

- Guard for the Parakeet TDT decoding loop (transformers #49388).
- Engine switches regenerate stale translated subtitles.
- Maltese translates correctly; corrupt safetensors downloads self-heal.
- Windows installer: FFmpeg pinned to a versioned gyan.dev build (the old
  autobuild had been deleted upstream).

## ✅ Validation

- Benchmarked on an RTX 5090 (Windows 11), an RTX 3080 Laptop and an Intel NUC
  CPU; tables in `docs/hardware_optimization.md`.
- Full quality gate green on Linux. On Windows, three pre-existing
  `test_input_binding.py` failures also occur on the v1.2.9 base.

## Breaking changes

- The default engine changes for the nine routed languages. Set
  `asr.engine: whisper` to keep the previous behaviour.
