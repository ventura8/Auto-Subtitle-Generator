# v1.1.2 Release Notes

Release date: 2026-07-16

## Highlights

- Enforced strict quality gates across local and CI workflows:
  - zero-suppression scanner
  - Ruff, Flake8, Pylint, mypy
  - Bandit and pip-audit
  - pytest warnings-as-errors + coverage enforcement
- Expanded lint/type coverage to include tests:
  - `pylint tests --errors-only`
  - `mypy auto_subtitle.py modules tests`
- Added a reusable release-preparation skill and workflow that derive release
  version from branch naming (for example `feature/v1.1.2`).

## Quality and Tooling

- Added security tooling dependencies:
  - `bandit`
  - `pip-audit`
  - `types-pyyaml`
- Tightened static analysis setup:
  - Ruff import sorting (`I`) enabled
  - mypy strict import handling (no global `ignore_missing_imports`)
  - local typing stubs under `typings/` for optional test imports
- Added repository-wide suppression policy scanner:
  - `tests/tools/check_no_suppressions.py`

## Pipeline Updates

- `run_local_pipeline.ps1` now enforces:
  - suppression scan
  - markdown checks
  - Ruff/Flake8/Pylint (including tests errors-only)
  - mypy including tests
  - Bandit + pip-audit
  - pytest coverage and per-file coverage thresholds
- `.github/workflows/ci.yml` now mirrors these gates and includes test lint/type
  checks.

## Reliability and Code Maintenance

- Removed warning-ignore suppression usage in runtime/config/translation paths.
- Added explicit typing improvements and optional import helper reuse to keep
  gates green without suppressions.
- Preserved project architecture constraints:
  - orchestration in `auto_subtitle.py`
  - implementation logic in `modules/`
  - atomic writes/resume/shutdown behavior maintained

## Documentation and Agent Updates

- Updated repository docs and quality guidance to reflect strict enforcement.
- Added release-prep workflow docs:
  - `.github/skills/release-prep/SKILL.md`
  - `.agent/workflows/release-prep.md`
- Added copy-ready GitHub release description:
  - `docs/releases/v1.1.2-github-release.md`
